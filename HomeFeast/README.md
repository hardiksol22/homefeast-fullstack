## ✨ Key Features

### 👨‍🍳 For Home Cooks (Providers)
- **Dedicated Dashboard:** Manage daily menus, track active subscribers, and view earnings.
- **Real Image Uploads:** Seamlessly upload actual dish photos via **Cloudinary** integration.
- **Order Management:** Track pending, active, and completed meal deliveries.

### 🍱 For Customers
- **Discovery Engine:** Browse top-rated local tiffin providers and home kitchens.
- **Smart Filtering:** Explore menus categorized by Diet (Veg, Non-Veg, Keto) and Subscription Plans (Daily, Weekly, Monthly).
- **Smooth Subscription Flow:** Select plans and place orders with real-time status tracking.

### 🛡️ System & Security
- **Role-Based Access Control (RBAC):** Distinct roles and protected routes for Customers, Cooks, and Admins.
- **Secure Authentication:** Encrypted passwords (Bcrypt) and secure API access using JSON Web Tokens (JWT).
- **Premium UI/UX:** Built with Tailwind CSS featuring a modern "Deep Midnight & Emerald" glassmorphism aesthetic.

## 🛠️ Tech Stack

**Frontend:**
- React.js (Vite)
- React Router DOM
- Tailwind CSS
- Context API (State Management)

**Backend:**
- Node.js & Express.js
- MongoDB & Mongoose
- Cloudinary & Multer (Image Processing)
- JWT & Bcrypt.js (Security)
